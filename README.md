# SkillMap

Интерактивная платформа профориентации: тест, рекомендации профессий, карта навыков, каталог курсов и личный кабинет.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Главная |
| `/test` | Тест из 13 вопросов |
| `/results` | Результаты и рекомендованные профессии |
| `/professions` | Каталог профессий с поиском и категориями |
| `/skills/:id` | Интерактивная карта навыков профессии |
| `/courses` | Каталог курсов с фильтрами (`?direction=Frontend&level=...&price=free`) |
| `/profile` | Личный кабинет |

## Структура

```
src/
  components/   Navbar, Sidebar, SkillCard, ProgressBar, CourseCard, ProfessionCard, QuestionCard, ProfessionIcon
  pages/        Home, Test, Results, Professions, SkillMap, Courses, Profile
  data/         questions, professions, skills, courses
  utils/        recommendations (подсчёт теста), skills (статусы навыков), storage (LocalStorage)
  context/      AppContext — общее состояние и сохранение прогресса
```

## Как считается результат

Каждый ответ добавляет баллы направлениям (программирование, дизайн, аналитика, инженерия, менеджмент).
Процент по направлению = набранные баллы / максимально возможные.
Совпадение с профессией = взвешенное среднее процентов по направлениям с весами профессии (`weights` в `professions.js`).

## Статусы навыков

- **Освоен** — отмечен пользователем.
- **Доступен** — все навыки из `requires` освоены.
- **Заблокирован** — есть неосвоенные требования.

Если снять отметку с навыка, отметки со всех зависимых от него навыков тоже снимаются.
Всё хранится в LocalStorage под ключом `skillmap_state_v1`.
